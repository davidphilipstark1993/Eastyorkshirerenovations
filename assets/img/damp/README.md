# Damp proofing before/after images

Before/after images for the damp proofing pages. See `docs/damp-image-prompts.md` for every filename, the AI prompt for each and how labelling works:

- `<slug>-before.jpg` / `<slug>-after.jpg`: real photos from EYR jobs (no badge)
- `<slug>-before-ai.jpg` / `<slug>-after-ai.jpg`: AI-generated images, shown with an "AI-generated illustration" badge

4:3 landscape JPGs (e.g. 1200 × 900). Run `node scripts/build-damp-proofing.mjs` after adding or changing images.
