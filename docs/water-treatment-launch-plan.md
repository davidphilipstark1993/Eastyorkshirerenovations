# Water Treatment — Launch Plan

Nine phases, as specified in the brief. This is a planning document only — no phase has been
executed beyond Phase 5 (website foundation, already built in a prior session) and the research
underpinning this plan (this session). No supplier has been contacted, nothing has been
purchased, and no compliance registration has been started.

## Phase 6 — Google/Meta lead generation
**Status: not started.**
- [ ] Recommendation from this research: **do not start here.** Begin with Phase 11 (cross-sell
      to existing customers) first — zero incremental ad spend, warmest possible audience, and a
      way to generate real conversion/economics data before spending on cold traffic.
- [ ] Once cross-sell has produced a handful of real jobs, test a small, geographically tight
      paid search campaign around "water softener Hull" / "water softener installation Hull" /
      "hard water Hull" (from the keyword list already used in the page's SEO), with a hard
      budget cap, to learn real UK CPC/CPL numbers for our own market — currently unknown (see
      unit economics document, Section 2).
- [ ] Re-run the unit economics model with real advertising cost data once available.

## Phase 7 — First 10 customers
**Status: not started.**
- [ ] Prioritise existing EYR renovation customers and direct referrals (Part 10/11 of the
      business model document) for the first cohort — lowest risk, highest trust, and generates
      real operational data (install time, callback rate, actual materials cost) to validate or
      correct the unit economics assumptions before scaling spend.
- [ ] Use these jobs to validate: actual install time per package tier, actual warranty/callback
      rate (currently just a 1.5–3% modelling assumption), actual customer questions/objections
      (to refine FAQ content).

## Phase 8 — Reviews/referrals
**Status: not started — and correctly so.**
- [ ] Do not publish testimonials/reviews for water treatment until real ones exist. The
      existing site's homepage reviews for general renovation work are real customer quotes
      (per the existing codebase's own pattern) — the water-treatment page currently has none,
      which is correct and should stay that way until genuine reviews exist. **Do not invent
      any.**
- [ ] Once Phase 7 produces real satisfied customers, ask for reviews using the same honest,
      no-pressure tone as the rest of the site.

## Phase 9 — Recurring aftercare
**Status: intentionally not started — see business model document, Part 19.**
